Therefore, $\tau m_{\gamma,r}(\o)$ lower-bounds the probability that one sample from the expanded CFM model lies in $A_{\gamma,r}(\o)\subseteq\Omega^\star(\o,\gamma)$. Likewise, $\left(1-\tau m_{\gamma,r}(\o)\right)^J$ upper-bounds the probability that none of the $J$ conditionally independent samples lies in this valid action set. Increasing $J$ increases the probability that a batch contains at least one valid action. Exploiting this bound at deployment, however, requires an online verifier mechanism, where this mode-selective generation is a common tool in CFM policy generation~\cite{mizuta2025unified}.
